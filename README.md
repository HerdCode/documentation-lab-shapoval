## 📌 Про проект
**MedReminder** — це зручний та інтуїтивно зрозумілий мобільний застосунок, створений для допомоги людям у своєчасному прийомі лікарських препаратів та вітамінів. Продукт вирішує проблему забудькуватості та недотримання графіку лікування, що є критично важливим для збереження здоров'я.

---

## ✨ Основні функції
- ⏰ **Гнучкі нагадування:** Налаштування сповіщень за часом, днями тижня або інтервалами.
- 📋 **Картка препарату:** Вказання дозування, інструкцій (до/після їжі) та залишкової кількості пігулок у упаковці.
- 👨‍👩‍👧 **Сімейний доступ:** Можливість відстежувати прийом ліків для літніх родичів або дітей.
- 📊 **Історія та звітність:** Генерація звітів про дотримання курсу для надання лікарю.
- 🔔 **Критичні сповіщення:** Повторні сигнали для важливих ліків, які не можна пропускати.

---

## 👤 Для кого цей продукт?
1. **Люди з хронічними захворюваннями**, яким необхідний щоденний прийом медикаментів.
2. **Літні люди**, яким важко утримувати графік прийому в голові.
3. **Батьки**, які контролюють лікування дітей.
4. **Спортсмени та прихильники ЗОЖ**, які приймають курси вітамінів та БАДів.
